Цей процес прийматиме файл архіву tar, стиснутий за допомогою gzip. Типове розширення файлу для цього формату архіву — ".tgz", але іноді також використовується розширення файлу ".tar.gz". Файли в архіві повинні мати таку номенклатуру: "hicn/beshare/icon.hvif". У цьому прикладі для пакунку "beshare" постачається векторна іконка HVIF.

Іноді дані векторних значків недоступні. У цьому випадку може бути надана комбінація зображень PNG розміром квадрата 16, 32 та 64 пікселів. У цьому випадку буде використана наступна номенклатура архівних записів «hicon/beshare/16.px».

Для кожного пакунку, значки якого змінено цим процесом, попередні дані значків будуть видалені.

Імпорт tar-файлу з іконками є «атомарним», що означає, що він або повністю обробить архів, або не змінить дані на стороні сервера. Це пов'язано з помилками виконання, такими як недійсні вхідні дані, які взагалі перешкоджають запуску процесу.

Про такі проблеми, як відсутність пакунків, а також успішне завантаження піктограми, повідомляється оператору через згенерований CSV-файл.
