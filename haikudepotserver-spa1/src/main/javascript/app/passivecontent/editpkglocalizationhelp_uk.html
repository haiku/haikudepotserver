Локалізація пакунку — це резервний варіант для значень локалізації, які зберігаються в даних пакунку (версія). Ліворуч розташовані різні мови. Виберіть мову, і її записи будуть відображені. Ви можете редагувати записи, а після завершення редагування записів для однієї або кількох мов ви можете скористатися кнопкою дії внизу сторінки, щоб зберегти дані. Під час відображення певний елемент локалізації (назва, короткий зміст або опис) вибирається в такому порядку пріоритету;

  1. Дані версії пакунку для мови користувача
  2. Резервні дані пакунку для мови користувача
  3. Дані версії пакунку для англійської мови
  4. Резервні дані пакунку для англійської мови
