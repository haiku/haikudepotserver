Репозиторій доступний для кількох різних архітектур. Кожна з яких доступна як окреме «джерело репозиторію». Джерело репозиторію має кілька дзеркал, одне з яких призначене як основне дзеркало, і саме звідти будуть отримані дані репозиторію для оновлення записів у HaikuDepotServer.

Поряд із фактичними даними репозиторію, також є файл repo.info з полем identifier. Це унікальний ідентифікатор для фактичного джерела репозиторію. Цей identifier поєднує дані HDS з репозиторієм, налаштованим у клієнтській програмі HaikuDepot для робочого столу застосунку.
